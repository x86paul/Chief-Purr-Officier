# Chief-Purr-Officier
The ultimate workspace companion deployed to assert feline dominance, monitor latency, and keep the humans entertained. Built with Node.js and Slack's Bolt framework, the CPO bot ensures your team stays sharp, educated, and properly judged.
# Core Functions:
cpo-ping – Checks the bot’s operational latency (or determines if the Chief is currently napping on the server rack).

cpo-catfact – Dispenses essential trivia and truth bombs straight from the feline empire.

cpo-joke – Generates standard-issue human humor to keep office morale high.
